# Test Fixtures

This directory contains example bundle data for testing the bundle ingestion system.

## Files

- `example-bundle.js` - A small JavaScript bundle with common patterns (functions, classes, module exports)
- `example-bundle.js.map` - Corresponding source map for the example bundle

## Usage

These fixtures can be used in tests to verify:

- Source map parsing
- AST symbol extraction
- Size calculation
- Complete ingestion pipeline
